# មេរៀនសង្ខេបសប្តាហ៍ទី ១ (Week 1 Lecture Notes)

**ប្រធានបទ៖** មូលដ្ឋានគ្រឹះ និងការរៀបចំឧបករណ៍កូដ (Foundations & Environment Setup)

---

## ថ្ងៃទី ១ និងទី ២៖ ស្វែងយល់ពីភាសា Rust និងឱកាសការងារ (Introduction & Use Cases)

### ១. តើអ្វីទៅជាភាសា Rust?

Rust គឺជាភាសាសរសេរកម្មវិធីទំនើប (Modern Programming Language) ដែលត្រូវបានបង្កើតឡើងក្នុងគោលបំណងកសាងសូហ្វវែរដែលមាន **ល្បឿនលឿន** **ភាពជឿជាក់ខ្ពស់** និងមាន**សុវត្ថិភាពអង្គចងចាំទាំងស្រុង** (Memory Safety) ដោយមិនចាំបាច់ប្រើប្រាស់ប្រព័ន្ធ Garbage Collector (ប្រព័ន្ធបោសសម្អាតកាកសំណល់ស្វ័យប្រវត្តដែលធ្វើឱ្យកម្មវិធីដើរយឺត) ឡើយ។

### ២. ហេតុអ្វីបានជាយើងជ្រើសរើសប្រើប្រាស់ Rust?

- **គ្មាន Garbage Collector៖** Rust គ្រប់គ្រងអង្គចងចាំតាមរយៈច្បាប់ច្បាស់លាស់នៅវគ្គបកប្រែកូដ (Compile Time) ធ្វើឱ្យកម្មវិធីដំណើរការបានលឿនបំផុត និងមិនស៊ីធនធានម៉ាស៊ីន។
- **ស្វែងរកកំហុសបានលឿន៖** Rust ជួយយើងស្វែងរក និងកែតម្រូវកំហុស (Bugs) តាំងពីវគ្គសរសេរកូដម៉្លេះ ដែលជួយសន្សំសំចៃពេលវេលាយ៉ាងច្រើនក្នុងវគ្គអភិវឌ្ឍកម្មវិធី។

### ៣. វិស័យកម្មវិធីដែលប្រើប្រាស់ Rust (Rust Use Cases)

ប្អូនៗអាចប្រើប្រាស់ Rust ដើម្បីបង្កើតកម្មវិធីក្នុងវិស័យជាច្រើនដូចជា៖

- **System Programming** — ការសរសេរកម្មវិធីកម្រិតប្រព័ន្ធ ឬឧបករណ៍បញ្ជាម៉ាស៊ីន
- **Command Line Interface (CLI) Tools** — ការបង្កើតឧបករណ៍បញ្ជាតាមផ្ទាំង Terminal
- **Game Development** — ការបង្កើតហ្គេម
- **Cloud Infrastructure** — ការរៀបចំប្រព័ន្ធពពក និង Cloud Native Services
- **Embedded Systems** — ការសរសេរកម្មវិធីបញ្ជាលើឧបករណ៍អេឡិចត្រូនិកខ្នាតតូច

### ៤. ឱកាសការងារសម្រាប់និស្សិត Rust

ការចេះភាសា Rust នឹងបើកឱកាសការងារធំៗចំនួន ៣៖

- **Software Developers៖** បង្កើតកម្មវិធីកម្រិតប្រព័ន្ធ សេវាកម្ម backend និង concurrent systems។
- **Cloud Engineers៖** រចនាសេវាកម្ម Cloud ដែលមានល្បឿនលឿន មិនស៊ីធនធាន និងងាយស្រួលពង្រីកមាត្រដ្ឋាន។
- **DevOps Engineers៖** បង្កើតឧបករណ៍ CLI រហ័ស និងស្វ័យប្រវត្តិកម្មសម្រាប់ប្រព័ន្ធ CI/CD។

## ថ្ងៃទី ៣៖ ការរៀបចំឡាបពិសោធន៍ និងឧបករណ៍សរសេរកូដ (Setting Up the Lab & IDEs)

ដើម្បីសរសេរកូដ Rust បាន ប្អូនៗត្រូវរៀបចំឧបករណ៍ដូចខាងក្រោម៖

### ១. ការដំឡើងភាសា Rust ក្នុងកុំព្យូទ័រ

1. ចូលទៅកាន់គេហទំព័រផ្លូវការ [rust-lang.org](https://rust-lang.org) រួចចម្លងកូដសម្រាប់ដំឡើងយកទៅរត់ក្នុង Terminal/PowerShell។
2. នៅពេលប្រព័ន្ធសួររកជម្រើស សូមជ្រើសរើសយកលេខ **1** (Proceed with standard installations)។

**របៀបផ្ទៀងផ្ទាត់ការដំឡើង៖** បើក Terminal ឡើងវិញ រួចវាយបញ្ជា៖

```powershell
rustc --version    # ដើម្បីពិនិត្យមើល Compiler របស់ Rust
cargo --version    # ដើម្បីពិនិត្យមើលកម្មវិធីគ្រប់គ្រងគម្រោង Cargo
```

### ២. ការជ្រើសរើសកម្មវិធីសរសេរកូដ (IDE)

- **VS Code (Visual Studio Code):** ជាជម្រើសចម្បងក្នុងថ្នាក់រៀនរបស់យើង។ កុំភ្លេចដំឡើង Extension ឈ្មោះ `rust-analyzer` ដើម្បីជួយណែនាំកូដ និងបង្ហាញកំហុសកូដភ្លាមៗ។
- **RustRover (JetBrains):** ជាកម្មវិធី IDE ដ៏មានឥទ្ធិពលមួយទៀតដែលបង្កើតឡើងសម្រាប់ Rust ផ្ទាល់។
- **OneCompiler (Browser-based):** សម្រាប់សរសេរ និងរត់កូដសាកល្បងលឿនៗនៅលើ Browser តាមរយៈអ៊ីនធឺណិត។
  > ចំណាំ៖ OneCompiler មានកម្រិតកំណត់លើកញ្ចប់កូដ ដូច្នេះមិនអាចប្រើសម្រាប់គម្រោងធំៗបានទេ។

## ថ្ងៃទី ៤ និងទី ៥៖ អថេរ និងប្រភេទព័ត៌មានគ្រឹះ (Variables, Mutability & Core Data Types)

### ១. ការប្រកាសអថេរ (Declaring Variables)

នៅក្នុង Rust យើងប្រើប្រាស់ពាក្យគន្លឹះ `let` ដើម្បីបង្កើតអថេរ។

- **ច្បាប់លំនាំដើម (Immutable by default)៖** អថេរទាំងអស់ដែលប្រកាសដោយ `let` គឺ **មិនអាចកែប្រែតម្លៃបានឡើយ** ដើម្បីបង្ការកំហុសទិន្នន័យដោយអចេតនា។
- **ការអនុញ្ញាតឱ្យកែប្រែតម្លៃ (Mutability)៖** ប្រសិនបើប្អូនៗចង់ឱ្យអថេរនោះអាចផ្លាស់ប្តូរតម្លៃបាន ប្អូនៗត្រូវបន្ថែមពាក្យគន្លឹះ `mut` ទៅជា `let mut`។

### ២. ប្រភេទទិន្នន័យគ្រឹះ (Core Data Types)

Rust បែងចែកប្រភេទព័ត៌មានច្បាស់លាស់ ដូចជា៖

- **ចំនួនគត់ (Integers)៖** ដូចជា `i32`, `u32` (ប្រើសម្រាប់ចំនួនគ្មានក្បៀស)។
- **ចំនួនទសភាគ (Floating-Point)៖** ដូចជា `f64` (ប្រើសម្រាប់លេខមានក្បៀស ដូចជាសីតុណ្ហភាព `35.5` ឬតម្លៃលុយ)។
- **អក្សរ (String)៖** សម្រាប់ផ្ទុកជាអត្ថបទ ឬពាក្យសម្តី។

### ៣. ការបង្ហាញលទ្ធផល និងការប្រើប្រាស់ម៉ាក្រូ (Output using `println!`)

យើងប្រើប្រាស់ម៉ាក្រូ `println!` (ត្រូវតែមានសញ្ញាឧទាន `!`) ដើម្បីបោះពុម្ពអត្ថបទ ឬតម្លៃអថេរទៅកាន់អេក្រង់។ សញ្ញា `{}` ដើរតួជាកន្លែងរង់ចាំទទួលតម្លៃពីអថេរដែលនៅខាងក្រោយ។
