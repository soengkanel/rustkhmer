# មេរៀនសង្ខេប៖ កំហុសទូទៅ ៤ យ៉ាងក្នុងកិច្ចការផ្ទះទី ១.២ (Common Errors in Assignment 1.2)

សួស្តីប្អូនៗនិស្សិតទាំងអស់គ្នា! ក្នុងនាមជាសាស្ត្រាចារ្យរបស់ប្អូនៗ នៅពេលដែលយើងអនុវត្តវិធីសាស្ត្រ **«រៀនតាមរយៈការអនុវត្តផ្ទាល់»** (Learning by Doing) គឺជារឿងធម្មតាណាស់ដែលប្អូនៗនឹងជួបប្រទះនូវកំហុសកូដ (Compile Errors) នៅពេលសរសេរកូដដំបូង។

កុំបារម្ភអី! នៅក្នុងភាសា Rust កំហុសទាំងនេះគឺជាមេរៀនដ៏ល្អបំផុត ហើយ **"បណ្ណារក្សដ៏តឹងរ៉ឹង"** (Compiler) តែងតែជួយចង្អុលបង្ហាញកំហុសយើងតាំងពីវគ្គដំបូង ដើម្បីកុំឱ្យកម្មវិធីមានបញ្ហានៅពេលដំណើរការ។

ខាងក្រោមនេះគឺជា **កំហុសឆ្គងទូទៅបំផុតទាំង ៤** (Common Errors) ដែលនិស្សិតតែងតែជួបប្រទះក្នុងការធ្វើ **កិច្ចការផ្ទះទី ១.២** (Assignment 1.2 – Temperature Converter) រួមជាមួយការពន្យល់ និងវិធីដោះស្រាយ៖

## ១. កំហុស "លាយឡំប្រភេទព័ត៌មាន" (Mismatched Types — Float vs. Integer)

នេះជាកំហុសដែលកើតឡើងញឹកញាប់ជាងគេបំផុត ដោយសារនិស្សិតទម្លាប់សរសេរកូដពីភាសាផ្សេងទៀត (ដូចជា Python ឬ JavaScript)។

**កូដដែលមានកំហុស (Incorrect):**

```rust
let celsius: f64 = 35.5;
let fahrenheit: f64 = (celsius * 9 / 5) + 32; // ❌ កំហុសត្រង់លេខ 9, 5, និង 32
```

**សារព្រមានរបស់ Compiler:**

```text
error[E0277]: cannot multiply `f64` by `{integer}`
```

**មូលហេតុ និងការពន្យល់របស់គ្រូ៖** Rust គឺជាភាសាដែលមានវិន័យតឹងរ៉ឹងបំផុតលើប្រភេទព័ត៌មាន (Strict Type Safety)។ វាមិនអនុញ្ញាតឱ្យយកលេខទសភាគ (`f64`) ទៅគុណ ឬចែកជាមួយចំនួនគត់ (Integer ដូចជា `9` ឬ `5`) ដោយស្វ័យប្រវត្តឡើយ។

**វិធីដោះស្រាយ (Correct):** ត្រូវបន្ថែមចំណុចទសភាគ `.0` ទៅលើលេខទាំងអស់ ដើម្បីឱ្យវាទៅជាប្រភេទ `f64` ដូចគ្នា៖

```rust
let fahrenheit: f64 = (celsius * 9.0 / 5.0) + 32.0; // ✅ ត្រឹមត្រូវ
```

## ២. កំហុស "ព្យាយាមកែប្រែតម្លៃអថេរ Immutable" (Reassigning Immutable Variables)

និស្សិតព្យាយាមផ្លាស់ប្តូរតម្លៃសីតុណ្ហភាព Celsius នៅក្នុងកូដ ប៉ុន្តែភ្លេចប្រកាសលក្ខណៈប្រែប្រួលរបស់វា។

**កូដដែលមានកំហុស (Incorrect):**

```rust
let celsius: f64 = 35.5;
celsius = 40.0; // ❌ កំហុស! មិនអាចផ្លាស់ប្តូរតម្លៃបានទេ
```

**សារព្រមានរបស់ Compiler:**

```text
error[E0384]: cannot assign twice to immutable variable `celsius`
```

**មូលហេតុ និងការពន្យល់របស់គ្រូ៖** នៅក្នុងភាសា Rust អថេរទាំងអស់ដែលប្រកាសដោយប្រើពាក្យគន្លឹះ `let` គឺ **មិនអាចកែប្រែតម្លៃបានឡើយ** (Immutable by default)។ នេះជាយន្តការការពារសុវត្ថិភាពទិន្នន័យរបស់ Rust។

**វិធីដោះស្រាយ (Correct):** ប្រសិនបើប្អូនៗចង់ឱ្យអថេរនោះអាចផ្លាស់ប្តូរតម្លៃបាន ប្អូនៗត្រូវបន្ថែមពាក្យគន្លឹះ `mut` (Mutability) នៅពីមុខអថេរនោះ៖

```rust
let mut celsius: f64 = 35.5; // ✅ បន្ថែម mut
celsius = 40.0;              // ✅ អាចផ្លាស់ប្តូរបានដោយគ្មានបញ្ហា
```

## ៣. កំហុស "ភ្លេចសរសេរសញ្ញាឧទាន `!` លើ `println!`" (Missing Exclamation Mark)

ពេលខ្លះ និស្សិតច្រឡំសរសេរវាដូចជាអនុគមន៍ធម្មតានៅក្នុងភាសាដទៃ។

**កូដដែលមានកំហុស (Incorrect):**

```rust
println("សីតុណ្ហភាព Celsius គឺ៖ {}", celsius); // ❌ ភ្លេចសញ្ញា !
```

**សារព្រមានរបស់ Compiler:**

```text
error[E0423]: expected function, found macro `println`
help: use `println!` instead
```

**មូលហេតុ និងការពន្យល់របស់គ្រូ៖** នៅក្នុង Rust `println!` **មិនមែនជាអនុគមន៍** (Function) ធម្មតាឡើយ វាគឺជា **ម៉ាក្រូ** (Macro)។ ម៉ាក្រូរបស់ Rust ត្រូវតែមានសញ្ញាឧទាន `!` នៅពីក្រោយជានិច្ច ដើម្បីឱ្យ Compiler ស្គាល់ និងដំណើរការបោះពុម្ពទិន្នន័យបានត្រឹមត្រូវ។

**វិធីដោះស្រាយ (Correct):**

```rust
println!("សីតុណ្ហភាព Celsius គឺ៖ {}", celsius); // ✅ មានសញ្ញា !
```

## ៤. កំហុស "រត់បញ្ជា Cargo ខុសទីតាំង" (Running Cargo Commands Outside Project Directory)

កំហុសនេះមិនមែនជាកំហុសកូដទេ តែជាកំហុសបច្ចេកទេសដំណើរការកម្មវិធី។

**សកម្មភាពខុស៖** និស្សិតបើក Terminal រួចវាយបញ្ជា `cargo run` ឬ `cargo check` ភ្លាមៗ ប៉ុន្តែប្រព័ន្ធបែរជាបង្ហាញសារកំហុស។

**សារព្រមានរបស់ Terminal:**

```text
error: could not find `Cargo.toml` in this directory or any parent directory
```

**មូលហេតុ និងការពន្យល់របស់គ្រូ៖** ឧបករណ៍ `cargo` ត្រូវការអានឯកសាររៀបចំគម្រោងដែលមានឈ្មោះថា `Cargo.toml` ដើម្បីដឹងពីរបៀបបង្កើត និងរត់កម្មវិធី។ ប្រសិនបើប្អូនៗមិនស្ថិតនៅក្នុងថត Folder របស់ Project ទេ នោះ Cargo នឹងរកឯកសារនេះមិនឃើញឡើយ។

**វិធីដោះស្រាយ (Correct):** ត្រូវប្រើបញ្ជា `cd` (Change Directory) ដើម្បីចូលទៅក្នុង Folder គម្រោងរបស់អ្នកជាមុនសិន រួចសឹមរត់បញ្ជា `cargo run`៖

```powershell
cd temp_converter
cargo run
```
